ASSISTENTE — V1

Aplicativo Windows para organizar demandas.
- Cadastro, edição e conclusão.
- Categorias livres.
- Urgência: Baixa, Normal, Alta e Crítica.
- Prazo opcional.
- Lembrete opcional com data/hora.
- Notificação na área de trabalho.
- Filtros por categoria e urgência.
- Ao fechar pelo X, permanece na bandeja para continuar lembrando.
- Dados locais em %APPDATA%\Assistente\tarefas.json.

A primeira versão mantém o aplicativo em segundo plano para que os lembretes funcionem. O próximo passo pode ser adicionar inicialização com o Windows, recorrência, agenda/calendário, busca e uma interface ainda mais refinada.
